# Security Policy

## Supported versions

The latest commit on `main` is supported. Plugins here are stdlib-only and run
locally; they read your Claude Code transcripts but never transmit them.

## Reporting a vulnerability

Responsible disclosure is appreciated. Report privately via either:

- GitHub's [private vulnerability reporting](https://github.com/SECOTRON/claude-plugins/security/advisories/new)
- Email [thomas@geens.be](mailto:thomas@geens.be)

Please include:

- Steps to reproduce or a proof-of-concept
- Affected plugin and version
- Relevant tool output or error messages

Please do not open a public issue for security reports.
