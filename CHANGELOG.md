# Changelog

Each plugin is versioned **independently** and keeps its own changelog. Releases
are automated with [release-please](https://github.com/googleapis/release-please);
per-plugin tags use the form `<plugin>-vX.Y.Z`.

## Plugins

- **session-finder** — [`plugins/session-finder/CHANGELOG.md`](plugins/session-finder/CHANGELOG.md)

> The `v0.1.0` tag is the marketplace's initial snapshot. Subsequent releases are
> per-plugin (e.g. `session-finder-v0.1.1`).
